\chapter{Supplementary Data}
\label{app:supplementary_data}

To facilitate reproducibility and further research, the raw datasets used for the Iloilo City network construction are hosted on GitHub. These files include the primary node data (\texttt{intersections.csv}), edge data (\texttt{roads.csv}), and the origin-destination pairs (\texttt{od-matrix.xlsx}) utilized in the computational modeling phase. The repository containing these files can be accessed at: \url{https://github.com/lueezzzz/iloilo-city-network-data}
